# Exact reconciliation review

Projects one unresolved synthetic month into a bounded review document. Every
amount names its statement or voucher evidence, decisions remain structurally
distinct from proposals, and correction lines remain drafts. Exported documents
can add explicit human decision edits, but re-import only emits checked ledger
command intents and rejects changes to amounts, provenance, states, or closure.

An independently verified certificate can produce a closed document; changing
the document itself can never manufacture that result.
